A task and performance tracker application built to help users seamlessly organize their day-to-day activities. 
- **Under the Hood:** Uses a layered architecture (Presentation, Business Logic, Data) to keep the code organized and maintainable.
- **Key Features:** Features a custom CSS Glassmorphism dashboard, a built-in analytics engine for stats processing, and an SQLite database for securely keeping track of tasks locally.

### 🎵 [Chim-eTunes: AI Music Recommender Chatbot](https://github.com/UPHSL-CCS-J3A/j3a-aiproject-chimkens)
> **Tech Stack:** Python, tkinter, Groq LLM, Spotify Web API, sentence-transformers

A chatbot project that helps users find personalized music recommendations based on their mood and preferences.
- **How it Works:** Uses an LLM to understand what the user is asking for, and applies semantic search across a database of track embeddings to find the nearest matches.
- **Features:** Integrates with the Spotify API so users can directly interact with their playlists, and considers audio features like tempo and energy to match the user's current mood.

A terminal-based game I made to practice programming core turn-based battle mechanics and data structures.
- **Learning Data Structures:** I used this project to learn and manually apply concepts like Linked Lists (for teams), Queues (for taking turns), Stacks (for logging critical hits), and Binary Trees (for saving battle history).
